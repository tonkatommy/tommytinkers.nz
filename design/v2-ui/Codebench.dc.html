> 01. what i build

Four kinds of digital work

Roughly. Most projects are a mix. If it lives on the web and you need it built, the answer is usually yes.

  • Websites

    Sites for businesses, makers and portfolios. Fast, accessible and easy for you to edit.

  • Web apps

    Logins, dashboards and real user data. Built so the next developer can read the code.

  • Internal tools

    Replace the spreadsheet, the inbox or the weekly report that eats your Friday.

  • Automations

    Small scripts that do the boring job every day, so you don't have to.
